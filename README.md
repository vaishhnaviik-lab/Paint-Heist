# 🎨 Paint Heist

**Paint Heist** is a fun and interactive browser-based game featuring a colorful chase between a cat and a rat.

## 🎮 Game Features
- Interactive gameplay
- Colorful game interface
- Keyboard-based controls
- Fun and engaging challenges

## 🕹️ How to Play
1. Open `Paint Heist.html` in your web browser.
2. Follow the on-screen instructions.
3. Use the game controls to play.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
Download the HTML file and open it in any modern web browser.
